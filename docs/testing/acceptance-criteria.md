# Forge Acceptance Criteria

## Current project-level acceptance
Forge is considered complete only when the implemented release can demonstrate:

- Neural-network model construction.
- Training.
- Evaluation.
- Inference.
- Classification workload.
- Regression workload.
- Image-based workload.
- Dataset loading and preprocessing.
- Model save/load.
- CPU execution.
- CUDA execution for supported workloads on compatible hardware.
- Reproducible benchmarks.
- Useful training/performance reporting.
- Clear errors for important invalid inputs.

## Milestone acceptance
A milestone is complete only when:
1. Its stated scope is implemented.
2. Its tests pass.
3. Required manual verification is complete.
4. No known critical defect violates its acceptance criteria.
5. Documentation affected by the change is updated.

## Evidence rule
Claims about CUDA, performance, or supported architectures require actual execution evidence.
